# Резак (мод для Teardown)

Болгарка для Teardown 2.x. English: [README.md](README.md).

**Зажмите ЛКМ на поверхности, проведите до конечной точки, отпустите.** Пока держите, пунктир показывает будущий рез,
красная точка - куда смотрит диск. После отпускания резак прорезает прямой пропил от точки нажатия до точки отпускания.

Как режет:

- линия делится на точки через 1,1 радиуса реза; для каждой луч находит настоящую поверхность (линия может идти через выступы и щели);
- в каждой точке диск идёт вглубь по нормали маленькими `MakeHole`, пока два шага подряд ничего не снимают (вышел с другой стороны) или не достигнута предельная глубина;
- материалы: мягкие (стекло, дерево, пластик, штукатурка, листва) всегда; слабый металл и бетон/кирпич через «средний» радиус; для `MakeHole` это один класс, поэтому мод различает их в каждой точке через `GetShapeMaterialAtPosition`. Бетон и кирпич стоят в 3 раза больше бюджета (режутся медленнее). Прочный металл и прочная кладка по умолчанию выключены;
- бюджет: 12 единиц за физический шаг на один рез (настройка), до 4 резов в очереди на игрока.

Эффекты: вращающийся диск на модели в руках, искры по металлу и бетону, опилки от дерева, пыль от бетона,
вой мотора, звуки раскрутки и остановки, звук резки, высота которого зависит от материала, свет в точке реза.

## Настройки

| Настройка | По умолчанию | Ключ |
|---|---|---|
| Ширина реза 0,1-0,4 м | 0,2 м | `savegame.mod.kerf` |
| Макс. глубина 0,2-3 м | 1 м | `savegame.mod.depth` |
| Макс. длина 0,5-10 м | 4 м | `savegame.mod.maxlen` |
| Дальность 2-15 м | 6 м | `savegame.mod.reach` |
| Дыр за шаг (скорость) 4-40 | 12 | `savegame.mod.budget` |
| Режет металл | да | `savegame.mod.metal` |
| Режет бетон и кирпич | да | `savegame.mod.masonry` |
| Бетон медленнее в x1-x6 | x3 | `savegame.mod.masonrycost` |
| Режет прочный металл | нет | `savegame.mod.hard` |
| Искры и пыль | да | `savegame.mod.sparks` |

## Установка, сборка, проверка

```powershell
New-Item -ItemType Junction -Path "$env:USERPROFILE\Documents\Teardown\mods\cutter" -Target "$PWD\mod"   # run inside the mod folder
..\_shared\.venv\Scripts\python tools\build_all.py
```

Mod Manager -> Local files -> Cutter -> включить; инструмент «Резак» в последней группе.

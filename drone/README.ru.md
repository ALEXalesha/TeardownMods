# Дрон с камерой (мод для Teardown)

Складной квадрокоптер, которым управляют с его камеры. English: [README.md](README.md).

| Ввод | Пешком (инструмент в руках) | В полёте |
|---|---|---|
| ЛКМ | запустить дрон / снова взять управление | сбросить бомбу на маркер |
| WASD | | полёт (относительно направления камеры) |
| Пробел / Ctrl | | вверх / вниз |
| Мышь | | обзор (поворот разворачивает дрон, наклон двигает подвес камеры) |
| Q | | вернуться в тело (дрон висит на месте) |
| P | | фоторежим: прячет HUD и помехи |
| R | сложить дрон (ближе 4 м), бомбы и батарея восстанавливаются | |

- Своя воксельная модель, четыре винта (столкновения винтов выключены); их вращение - полупрозрачный размытый диск, который рисует клиент: двигать формы летящего тела каждый тик значит спорить с физикой (сама игра так никогда не делает). Мигающие огни (на сервере: тело дрона создаёт сервер), фонарь снизу, гул, громкость и высота которого следуют за тягой.
- Полёт: сервер каждый шаг физики задаёт скорость тела (плавно догоняет управление, гравитация шага вычитается) и поворачивает его через угловую скорость, дрон держится ровно и наклоняется в сторону движения. Без ввода висит на месте и держит высоту.
- Батарея (3 мин по умолчанию, при большой тяге тратится быстрее): когда кончается, моторы встают и дрон падает.
- Дальность связи (150 м по умолчанию): с 75% дальности картинка шумит (помехи, полосы, звук помех); дальше связь теряется, ввод не действует, дрон медленно снижается.
- Авария: изменение скорости больше 9 м/с за физический шаг (свой толчок мод вычитает) разбивает дрон на обломки; управление возвращается игроку.
- Бомбы: 3 за полёт. Если включён мод «Гравитационная граната», сброс передаётся ему через реестр
  (`level.singularity_grenade.req.<n>.*`, см. README того мода): падает настоящая граната со скоростью дрона. Иначе дрон бросает свою бомбу, которая взрывается от удара (`Explosion`, сила 1,0).
- Маркер цели: кольцо на земле там, куда упадёт бомба, если сбросить сейчас (баллистическая оценка по текущей скорости).

## Что позволяет API

- Полёт задаёт скорость тела каждый шаг физики с вычтенной гравитацией этого шага и поворачивает тело через угловую скорость, поэтому дрон висит точно и слушается одинаково при любом FPS. WASD/Пробел/Ctrl доходят до сервера двумя путями: клиент шлёт их через `ServerCall`, а сервер сам читает их с номером игрока, как турель самой игры (`data/level/carib/script/turret.lua`). Тело пилота держится на месте по позиции, а не через `DisablePlayerInput`: меню спавна игры использует этот вызов именно чтобы глушить ввод игрока для других скриптов.
- Фоторежим: функции скриншота в `script_defs.lua` нет (`Command` помечен устаревшим и даёт только запись экрана игры), поэтому фоторежим прячет HUD, а снимок делается клавишей скриншота Steam (F12).
- Сброс гранаты из другого мода работает только потому, что оба мода наши и договорились о ключах реестра; общего способа вызвать код чужого мода в Teardown нет.

| Настройка | По умолчанию | Ключ |
|---|---|---|

| Батарея ограничена / без ограничений | ограничена | `savegame.mod.battery` |
| Батареи хватает на 1-10 мин | 3 | `savegame.mod.minutes` |

| Строка отладки (для проверки) | да | `savegame.mod.debug` |

## Запасной режим и строка отладки

Если тело не следует за скоростью, которую задаёт мод (клавиша зажата, а движения нет 0,5 с, или дрон проседает без нажатий), дрон переходит в **кинематический полёт**: тело делается статичным и каждый шаг физики переставляется через `SetBodyTransform`, у стен останавливается (луч), так что он летает, даже если движок игнорирует скорость из скрипта. Во время полёта внизу слева жёлтая строка: `drone: mode velocity|kinematic | client <клавиши> | server <клавиши> | sent <клавиши> | speed | camera | crashes` - клавиши, которые видит клиент, которые сервер читает с номером игрока, и которые пришли через `ServerCall`. `tests/fallback_law.lua` проверяет это в стенде, где `SetBodyVelocity` не действует: дрон не проседает, переключается примерно за полсекунды, пролетает 10+ м за 2 с, поднимается и висит; `tests/flight_law.lua` проверяет, что обычный полёт не переключается.

## Установка, сборка, проверка

```powershell
New-Item -ItemType Junction -Path "$env:USERPROFILE\Documents\Teardown\mods\drone" -Target "$PWD\mod"   # запускать в папке мода
..\_shared\.venv\Scripts\python tools\build_all.py
```

Mod Manager -> Local files -> Camera Drone -> включить; инструмент «Дрон с камерой» в последней группе.

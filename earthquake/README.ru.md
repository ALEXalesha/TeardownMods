# Землетрясение (мод для Teardown)

Сейсмический детонатор для Teardown 2.x. English: [README.md](README.md).

- **ЛКМ** запускает землетрясение в точке прицела (или под игроком, см. настройки). Повторное нажатие останавливает.
- **ПКМ** переключает силу: слабое, умеренное, сильное, разрушительное, катастрофическое.

Что делает толчок:

- динамические тела и машины в радиусе получают импульсы по изменению скорости грунта (чуть со смещением, поэтому вещи качаются и падают); тяжёлое получает меньше;
- игрока на земле дёргает (начиная с умеренного), камера трясётся, играет гул, вокруг слышен треск;
- с земли поднимается пыль, с потолков вокруг игрока сыплется крошка;
- разрушения в пределах бюджета: случайные пробы возле построек, `MakeHole` только по разрешённым материалам:
  умеренное ломает стекло, дерево, штукатурку, пластик; сильное добавляет бетон, кирпич и слабый металл; катастрофическое задевает и твёрдый металл с прочной кладкой.
  Слабые здания дальше рушатся сами за счёт физики Teardown;
- соединения (петли, тросы, шарниры) трясущихся тел отрываются с вероятностью, растущей с силой;
- афтершоки по желанию (2-3, слабее и короче, через 8-22 с).

Тряска - детерминированная функция времени и зерна, поэтому сервер (силы) и клиент (камера, сейсмограф)
считают одно и то же без передачи данных.

## Настройки

| Настройка | Диапазон | По умолчанию | Ключ |
|---|---|---|---|
| Длительность | 5-60 с | 15 с | `savegame.mod.duration` |
| Сила по умолчанию | слабое..катастрофическое | сильное | `savegame.mod.preset` |
| Радиус | 20-150 м | 60 м | `savegame.mod.radius` |
| Афтершоки | да / нет | да | `savegame.mod.aftershocks` |
| Разрушение построек | да / нет | да | `savegame.mod.damage` |
| Тряска камеры | x0-x2 | x1 | `savegame.mod.shake` |
| Эпицентр | точка прицела / под игроком | точка прицела | `savegame.mod.atplayer` |

## Бюджет

- один `QueryAabbBodies` раз в 0,25 с, до 220 тел, 55 импульсов за физический шаг (по кругу);
- дыры: 1-5 проб `QueryClosestPoint` за шаг, не больше 450 дыр за толчок;
- соединения: проверка раз в 0,3 с, не больше 2 оторванных за проверку;
- частицы: до 16 за шаг рядом с игроком.

## Установка, сборка, проверка

```powershell
New-Item -ItemType Junction -Path "$env:USERPROFILE\Documents\Teardown\mods\earthquake" -Target "$PWD\mod"   # run inside the mod folder
..\_shared\.venv\Scripts\python tools\build_all.py
```

В игре: Mod Manager -> Local files -> Earthquake -> включить; инструмент «Сейсмический детонатор» в последней группе.

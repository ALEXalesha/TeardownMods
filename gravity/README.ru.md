# Смена гравитации (мод для Teardown)

Меняет гравитацию на всём уровне. English: [README.md](README.md).

| Клавиша | Действие |
|---|---|
| G (нажать; в настройках можно K) | следующий режим: Земля -> Луна -> Марс -> невесомость -> обратная -> вбок -> Земля |
| G (держать 0,8 с) | вернуть Землю |
| Пробел / Ctrl в невесомости | вверх / вниз |

| Режим | Гравитация |
|---|---|
| Земля | (0, -10, 0), значение Teardown по умолчанию |
| Луна | -1,62 м/с² |
| Марс | -3,71 м/с² |
| Невесомость | 0 |
| Обратная | +4 м/с² вверх (настройка 1-10) |
| Вбок | 6 м/с² вправо от вас в момент выбора (настройка 2-10) |

## Как устроено

- Настоящая гравитация: `SetGravity` для всей сцены (только из серверного кода: пример в `script_defs.lua` использует `server.tick`; харнесс теперь ловит вызовы с клиента). Смена плавная, 1,5 с (настройка 0-5 с). При перезапуске уровня игра сама возвращает обычную гравитацию. Если гравитацию сцены сбросили, а в моде выбран другой режим (состояние скрипта сохранилось, например при быстрой загрузке), сервер ставит его снова на следующем тике; на Земле мод гравитацию сцены не трогает (закон `tests/quickload_law.lua`).
- Лежащие тела спят и не заметят новой гравитации, поэтому мод будит динамические тела в радиусе 60 м от игроков через `SetBodyActive`, по 40 за тик, список обновляется раз в секунду.
- Игрок подчиняется гравитации сцены (на Луне прыжки и так выше). В невесомости игрок держится ровно через `SetPlayerOrientation`, а Пробел / Ctrl толкают вверх и вниз с небольшим торможением.
- Индикатор справа вверху: название режима, сила в g, стрелка, куда сейчас «низ» относительно взгляда (в невесомости кольцо), и ход смены. При слабой гравитации вокруг парят пылинки, в невесомости звучит тихий гул, каждая смена отмечена звуком.
- Автовозврат Земли через 10, 30 или 60 с, удобно для обратной гравитации.

## Настройки

| Настройка | По умолчанию | Ключ |
|---|---|---|
| Клавиша G / K | G | `savegame.mod.key` |
| Плавность 0-5 с | 1,5 с | `savegame.mod.trans` |
| Сила обратной | 4 м/с² | `savegame.mod.reverse` |
| Сила боковой | 6 м/с² | `savegame.mod.sideways` |
| Вернуть Землю через | никогда | `savegame.mod.autoreturn` |
| Будить предметы в радиусе | 60 м | `savegame.mod.wakeradius` |
| Двигатели в невесомости | вкл | `savegame.mod.thrusters` |
| Индикатор | показывать | `savegame.mod.indicator` |

## Установка, сборка, проверка

```powershell
New-Item -ItemType Junction -Path "$env:USERPROFILE\Documents\Teardown\mods\gravity" -Target "$PWD\mod"   # запускать в папке мода
..\_shared\.venv\Scripts\python tools\build_all.py
```

Mod Manager -> Local files -> Gravity Change -> включить. Это не инструмент, клавиша работает с чем угодно в руках.

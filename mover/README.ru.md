# Перемещатель (мод для Teardown)

Пушка-гизмо для Teardown 2.x, которая двигает предметы. English: [README.md](README.md).

| Клавиша | Действие |
|---|---|
| Держать ЛКМ | схватить динамическое тело в прицеле (предметы, обломки, машины); отпустить - бросить |
| Колесо мыши | дальше / ближе по взгляду (переключение инструментов заблокировано, пока держите) |
| Q / R | поворот вокруг вертикали |
| Z / X | наклон вперёд-назад |
| V / B | крен |
| T | заморозить тело в прицеле или в руках / разморозить |
| G | копия рядом с оригиналом |
| N / M | пересчёт вокселей x0,5 / x2 (опытная функция, небольшие предметы) |
| U | отменить последнее перемещение, заморозку или клон |

Схваченное тело обведено голубым контуром и соединено лучом с пушкой, замороженные - синим,
тело в прицеле - белым. Справа панель с клавишами (отключается в настройках).

## Как устроено и что позволяет API

- Динамические тела переносятся через `ConstrainPosition` + `ConstrainOrientation` в `server.update`, поэтому они продолжают сталкиваться.
  Машины двигаются за главное тело (`GetVehicleBody`), колёса тянутся через свои соединения.
- Заморозка - `SetBodyDynamic(body, false)`; замороженные переносятся через `SetBodyTransform`.
  Статичную геометрию уровня (здания, которые не были динамическими, землю) схватить **нельзя**: сделать
  мировое тело динамическим значит развалить уровень, поэтому мод отказывает.
- Клон: `Spawn` статичного тела-заглушки из одного вокселя, затем `CreateShape` + `CopyShapeContent` для каждой формы,
  заглушка удаляется, тело становится динамическим. Соединения, лампы и скрипты оригинала не копируются; машины не клонируются.
- Масштаб: в API нет способа поменять размер вокселя у формы. Поэтому мод пересчитывает воксели: новая форма через
  `CreateShape`/`ResizeShape`, чтение `GetShapeMaterialAtIndex`, запись отрезками через `SetBrush` + `DrawShapeBox`
  (x2: каждый воксель становится кубом 2x2x2; x0,5: один воксель на блок 2x2x2). Работа растянута на несколько шагов
  (2500 чтений за шаг) с полоской прогресса; ограничения: 8 форм, 60 000 клеток, до 128 вокселей по стороне.
  Новое тело встаёт на место нижнего центра старого.
- Отмена хранит 12 последних действий на игрока (перемещение, заморозка, клон). Масштаб не отменяется.
- Клавиши читаются на клиенте (сырые клавиши не передаются по сети) и уходят на сервер через `ServerCall`.

## Настройки

| Настройка | По умолчанию | Ключ |
|---|---|---|
| Макс. дальность 5-100 м | 40 м | `savegame.mod.maxdist` |
| Скорость переноса 5-40 м/с | 20 | `savegame.mod.speed` |
| Привязка к сетке нет/0,1/0,25/0,5/1 м | нет | `savegame.mod.possnap` |
| Шаг поворота нет/15/45/90° | нет | `savegame.mod.rotsnap` |
| Скорость поворота 30-360°/с | 90 | `savegame.mod.rotspeed` |
| Клонирование | вкл | `savegame.mod.clone` |
| Масштаб | вкл | `savegame.mod.scale` |
| Подсказка клавиш | показывать | `savegame.mod.help` |

## Установка, сборка, проверка

```powershell
New-Item -ItemType Junction -Path "$env:USERPROFILE\Documents\Teardown\mods\mover" -Target "$PWD\mod"   # run inside the mod folder
..\_shared\.venv\Scripts\python tools\build_all.py
```

Mod Manager -> Local files -> Mover -> включить; инструмент «Перемещатель» в последней группе.

# Портальная пушка (мод для Teardown)

Синий и оранжевый порталы. English: [README.md](README.md).

| Ввод | Действие |
|---|---|
| ЛКМ | поставить синий портал |
| ПКМ | поставить оранжевый портал |
| R | закрыть оба портала |

## Что позволяет API (проверено по `script_defs.lua`)

| Возможность | Итог |
|---|---|
| Телепорт игрока с сохранением инерции | да: `SetPlayerTransformWithPitch` (он обнуляет скорость), затем `SetPlayerVelocity` со скоростью, повёрнутой в систему выхода; взгляд (поворот и наклон) поворачивается так же |
| Телепорт динамических тел | да: `SetBodyTransform` + `SetBodyVelocity` + `SetBodyAngularVelocity`, всё повёрнуто |
| Видеть сквозь портал | **нет**: функций отрисовки в текстуру, зеркал или камер-трансляций нет (экраны в мире только выполняют UI-скрипты). Поверхность портала - анимированный вихрь (`DrawSprite`, два слоя крутятся навстречу, сложение цвета) с пульсирующей светящейся каймой, искрами и цветным светом |

## Как устроено

- Установка: луч из глаз (100 м по умолчанию). Место должно быть ровным и сплошным на размер портала (четыре луча вокруг центра попадают в одну плоскость с точностью 12 см, нормали в пределах ~25°) и свободным спереди; нельзя ставить поверх другого портала. По умолчанию только на неподвижные поверхности (настройка: разрешить подвижные, тогда портал едет вместе с телом). Неудача - шипение и искры.
- Ориентация: на стенах «верх» портала - мировой верх; на полу и потолке «верх» - направление взгляда, поэтому из пола в стену вы выходите туда, куда смотрели.
- Проход: вход в A вдоль нормали и выход из B - это отображение локальных координат (x, y, z) -> (-x, y, -z). Через него проходят положения, скорости и повороты. На выходе не меньше 2 м/с (игрок) / 1 м/с (предметы) наружу, чтобы никто не застрял.
- Игрок: точка капсулы (ноги, центр или голова), ближайшая к плоскости портала, должна оказаться ближе 0,5 м внутри контура портала и не удаляться. Встав на портал в полу, вы проваливаетесь.
- Без «пинг-понга»: после каждого телепорта у игрока и у каждого предмета своя пауза 1 с, и прежде чем выходной портал сможет снова их забрать, нужно отойти от него хотя бы на 1 м.
- Предметы: проверка каждый физический шаг возле каждого портала, с упреждением на шаг, чтобы быстрые броски ловились до отскока от стены. Предмет проходит, если помещается в контур, а центр масс подходит к плоскости ближе своей полутолщины + 15 см. Предметы больше портала просто бьются о стену (состояния «наполовину внутри» нет). Машины не телепортируются (колёса - отдельные тела). Предел 500 кг (настройка).
- Разрушение поверхности: каждые 0,25 с три луча проверяют, что поверхность под порталом на месте; если нет - портал закрывается со звуком.

Звуки: два выстрела, открытие, закрытие, проход, шипение неудачи и гул у каждого открытого портала.

## Настройки

| Настройка | По умолчанию | Ключ |
|---|---|---|
| Дальность 20-200 м | 100 м | `savegame.mod.range` |
| Размер: маленький / обычный / большой | обычный | `savegame.mod.size` |
| Предметы проходят | да | `savegame.mod.bodies` |
| Самый тяжёлый предмет 50-3000 кг | 500 | `savegame.mod.masslimit` |
| Порталы на подвижных предметах | нет | `savegame.mod.dynamic` |
| Громкость гула | 0,5 | `savegame.mod.hum` |

## Установка, сборка, проверка

```powershell
New-Item -ItemType Junction -Path "$env:USERPROFILE\Documents\Teardown\mods\portal-gun" -Target "$PWD\mod"   # запускать в папке мода
..\_shared\.venv\Scripts\python tools\build_all.py
```

Mod Manager -> Local files -> Portal Gun -> включить; инструмент «Портальная пушка» в последней группе.

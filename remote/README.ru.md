# Радиоуправление (мод для Teardown)

Управляйте любой машиной дистанционно, как радиоуправляемой, оставаясь на месте. English: [README.md](README.md).

| Ввод | Действие |
|---|---|
| ЛКМ по машине | взять на радиоуправление (подходит любая её часть, колёса тоже); по другой машине во время езды - пересесть |
| W / S | газ / задний ход |
| A / D | руль |
| Пробел | ручник |
| V | камера за машиной вкл / выкл (мышь её крутит) |
| Q | отпустить |

- Настоящее вождение: `DriveVehicle(vehicle, drive, steering, handbrake)` каждый тик из серверного кода (так же делает `truxterminator.lua` самой игры). Машины принадлежат серверу, поэтому клиент их только читает и отправляет свой ввод через `ServerCall`, когда он меняется; никаких фокусов с силами.
- Пока вы ведёте машину, тело игрока держится через `DisablePlayerInput` (настройка), поэтому WASD управляет только машиной.
- Камера за машиной: сзади и сверху, мышь крутит её, перед стенами она подтягивается ближе; V возвращает вид из глаз.
- Пересадка с включённой камерой за машиной целится из этой камеры (сервер сам повторяет луч и проверяет, что он идёт от управляемой машины); если луч из центра никого не задел, берётся машина в пределах 10° от взгляда, если и её нет - то, на что смотрит само тело. Зажатые клавиши сразу действуют на новую машину.
- Дальность сигнала 150 м: с 75% картинка шумит и слышны помехи; дальше связь теряется, машина тормозит ручником и через 3 с отпускается, всё это время тело держится. Если игрок погиб, машина отпускается.
- Управляемая машина обведена голубым, машина в прицеле - белым. На экране: скорость, повреждения (`GetVehicleHealth`), сигнал, клавиши.
- Машину, которой управляет или в которой сидит другой игрок, взять нельзя. Если машина исчезла, управление заканчивается.

## Настройки

| Настройка | По умолчанию | Ключ |
|---|---|---|
| Дальность связи 30-500 м | 150 м | `savegame.mod.range` |
| Дистанция захвата 10-200 м | 80 м | `savegame.mod.aimrange` |
| Камера за машиной сразу включена | да | `savegame.mod.follow` |
| Дистанция камеры 3-20 м | 7 м | `savegame.mod.camdist` |
| Тело игрока стоит | да | `savegame.mod.freeze` |
| Чувствительность мыши | x1 | `savegame.mod.sens` |

## Установка, сборка, проверка

```powershell
New-Item -ItemType Junction -Path "$env:USERPROFILE\Documents\Teardown\mods\remote" -Target "$PWD\mod"   # запускать в папке мода
..\_shared\.venv\Scripts\python tools\build_all.py
```

Mod Manager -> Local files -> Vehicle Remote -> включить; инструмент «Пульт радиоуправления» в последней группе.

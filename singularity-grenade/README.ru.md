# Гравитационная граната (мод для Teardown)

Метательный инструмент для Teardown 2.x. Граната летит физическим телом,
отскакивает, потом поднимается и раскрывается в короткоживущую сингулярность:

- тянет к ядру незакреплённые динамические тела, обломки и игроков (сила падает с расстоянием, тяжёлое сопротивляется);
- тела у ядра сжимаются на тугую вращающуюся орбиту;
- пробивает небольшие дыры в стекле, дереве, пластике, штукатурке и листве вокруг (металл, бетон, кирпич и камень не трогает);
- через несколько секунд схлопывается: белая вспышка, толчок наружу, который раскидывает всё собранное, и тёмный след.

English version: [README.md](README.md).

## Управление

| Ввод | Действие |
|---|---|
| Удерживать ЛКМ, отпустить | Бросок. Чем дольше держать (до 1 с), тем дальше |
| ПКМ | Короткий бросок под ноги (не срабатывает, если смотрите на предмет, который можно взять) |

Граната раскрывается через 1,5 с после остановки (по умолчанию) или сразу после первого удара (настройка).
Боезапас 5, перезарядки нет. В песочнице игра даёт бесконечные патроны, мод их не тратит.
Одновременно в мире не больше 4 гранат, при упоре в лимит HUD об этом пишет.

## Настройки (Менеджер модов -> Гравитационная граната -> Options)

| Настройка | Диапазон | По умолчанию | Ключ |
|---|---|---|---|
| Радиус | 3-20 м | 8 м | `savegame.mod.radius` |
| Сила | x0,2-x3 | x1 | `savegame.mod.strength` |
| Длительность | 1-15 с | 4 с | `savegame.mod.duration` |
| Боезапас | 1-50 | 5 | `savegame.mod.ammo` |
| Раскрытие | после остановки / от удара | после остановки | `savegame.mod.impact` |
| Тянет игрока | да / нет | да | `savegame.mod.pullplayer` |
| Урон игроку | нет / слабый / сильный | слабый | `savegame.mod.damage` |
| Рвёт слабые материалы | да / нет | да | `savegame.mod.tear` |
| Настоящий взрыв в конце | да / нет | нет | `savegame.mod.blast` |

Радиус, сила, длительность и режим раскрытия читаются при каждом броске. Боезапас - при старте уровня.

## Установка для проверки

Собранный мод - папка `mod/`. Связать её с папкой локальных модов:

```powershell
New-Item -ItemType Junction -Path "$env:USERPROFILE\Documents\Teardown\mods\singularity-grenade" -Target "$PWD\mod"   # run inside the mod folder
```

В игре: Mod Manager -> Local files -> Singularity Grenade -> включить. Инструмент появится в панели
инструментов (колесо мыши / цифры, последняя группа).

## Сборка и проверка

```powershell
cd <repo>\_shared
python -m venv .venv
.venv\Scripts\python -m pip install lupa numpy pillow
cd ..\singularity-grenade
..\_shared\.venv\Scripts\python tools\build_all.py
```

`build_all.py` заново генерирует модель, звуки и картинки, запускает статическую проверку
(компиляция Lua 5.1, каждая функция API есть в `script_defs.lua`, все файлы `MOD/` на месте, info.txt)
и харнесс: настоящий `main.lua` и `options.lua` гоняются против поддельного движка, собранного из
`script_defs.lua`, около 4800 кадров, дважды: в одной Lua-машине и с раздельными сервером и клиентом.
Для звуков нужен ffmpeg с libvorbis в PATH.

## Бюджет производительности

- один `QueryAabbBodies` на сингулярность раз в 0,2 с, не больше 120 отслеживаемых тел;
- импульс получают не больше 40 тел за физический шаг на сингулярность (по кругу, импульс масштабируется);
- дыры: 2 луча раз в 0,12 с (4 луча раз в 0,05 с при схлопывании), не больше 48 дыр на гранату;
- толчок при схлопывании растянут на несколько шагов, 50 тел за шаг, максимум 160;
- частицы: не больше 40 за шаг на все сингулярности плюс разовая вспышка из 80 частиц.

## Ограничения

- HUD игры показывает у модовых инструментов только имя, иконка используется в интерфейсе мода и превью.
- Проверено только офлайн; силу притяжения, орбиту и толчок, возможно, придётся подстроить в игре.

## Для других модов

Другие скрипты могут сбросить гравитационную гранату (так делает мод с дроном) через реестр:
записать `level.singularity_grenade.req.<n>.x/y/z/vx/vy/vz` (float) и `.owner` (int), затем поставить
`level.singularity_grenade.reqcount` = `n`. Мод создаст гранату на следующем тике без траты боезапаса и
сотрёт ключи. Когда мод загружен, он ставит `level.singularity_grenade.available = true`.

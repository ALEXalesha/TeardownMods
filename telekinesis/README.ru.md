# Телекинез (мод для Teardown)

Перчатка телекинеза. English: [README.md](README.md).

| Ввод | Действие |
|---|---|
| ЛКМ (руки свободны) | поднять незакреплённые предметы вокруг точки прицела |
| Держать ЛКМ (когда держите) | заряд; отпустите - бросок очередью по взгляду |
| ПКМ | аккуратно опустить |

- Захват: луч находит точку прицела (40 м), затем берутся ближайшие динамические тела в радиусе 3 м от неё: до 8, каждое до 200 кг. Машины и игроков не берёт.
- Удержание: тела тянутся через `ConstrainPosition` (серверный `update`) к местам на медленно вращающемся кольце в 3 м перед вами; при заряде кольцо сжимается, крутится быстрее и приближается.
- Бросок: предметы вылетают по одному каждые 0,04 с (очередь), скорость 14-54 м/с в зависимости от заряда и силы броска, тяжёлые чуть медленнее, с небольшим разбросом и вращением.
- Энергия: удержание тратит её - заданное время (15 с) указано для груза около 200 кг, лёгкого хватает дольше (не больше чем вдвое), тяжёлого - меньше; бросок стоит от 5% (быстрый) до 15% (полный заряд); когда энергия кончается, предметы падают. Начинает восстанавливаться через 0,8 с после того, как руки освободились, и полная снова через 0,6 заданного времени (9 с). Можно выключить. Закон: `tests/energy_text_law.lua`.
- Удерживаемые предметы обведены фиолетовым и подсвечены; от руки к ним идут струйки, вокруг искры; гул растёт с зарядом; шар перчатки ярче при заряде.
- Если убрать инструмент, всё падает. Тела двигает только серверный код, клиенты их только читают.

## Настройки

| Настройка | По умолчанию | Ключ |
|---|---|---|
| Радиус захвата 1-8 м | 3 м | `savegame.mod.radius` |
| Макс. предметов 1-20 | 8 | `savegame.mod.maxbodies` |
| Самый тяжёлый предмет 10-1000 кг | 200 кг | `savegame.mod.masslimit` |
| Сила броска | x1 | `savegame.mod.power` |
| Дальность 5-100 м | 40 м | `savegame.mod.reach` |
| Шкала энергии | вкл | `savegame.mod.energy` |
| Энергии хватает на 5-60 с | 15 с | `savegame.mod.capacity` |

## Установка, сборка, проверка

```powershell
New-Item -ItemType Junction -Path "$env:USERPROFILE\Documents\Teardown\mods\telekinesis" -Target "$PWD\mod"   # запускать в папке мода
..\_shared\.venv\Scripts\python tools\build_all.py
```

Mod Manager -> Local files -> Telekinesis -> включить; инструмент «Телекинез» в последней группе.

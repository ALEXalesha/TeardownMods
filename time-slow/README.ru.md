# Замедление времени (мод для Teardown)

Удерживайте клавишу, чтобы замедлить мир. English: [README.md](README.md).

- **H** (удерживать или нажать-отжать; клавиша на выбор: H, Y, T или средняя кнопка мыши) - замедление;
- **J** - сменить скорость: x0,5, x0,25, x0,1;
- плавный вход и выход (0,05-1,5 с, считается по реальному времени через `GetTime`, поэтому сам не замедляется);
- синий оттенок и обесцвечивание через `SetPostProcessingProperty("saturation" / "colorbalance")`; исходные значения читаются при входе и возвращаются при выходе;
- глухая музыка (`SetMusicLowPass`), сердцебиение (`UiSoundLoop`), звук входа и выхода, синяя виньетка;
- шкала энергии: тратится в замедлении (8 с по умолчанию), восстанавливается через 1 с после отпускания (12 с до полной); когда кончается, эффект выключается и заблокирован до 30%. Можно выключить;
- на экране: песочные часы, текущая скорость, полоска энергии.

## Что позволяет API

- `SetTimeScale(scale)` принимает 0..2 и вызывается каждый кадр из tick. По документации игры, начиная с 1.5 он
  работает через интерполяцию отрисовки и не меняет поведение физики. Мод не опускается ниже 0,1.
- Отдельного времени для игрока нет, поэтому игрок тоже замедляется. Опция «быстрее ходьба» поднимает
  `SetPlayerWalkingSpeed` в 1/scale раз (до x4) на сервере. Это приближение: прыжки, падение, поворот камеры и инструменты остаются замедленными.
- Звуки мира движок сам понижает по высоте; фильтра для звуков мира в API нет, только для музыки.
- В мультиплеере замедление вызывается на клиенте; применяет ли его движок ко всем - не проверено.

## Настройки

| Настройка | По умолчанию | Ключ |
|---|---|---|
| Клавиша: H / Y / T / средняя кнопка | H | `savegame.mod.key` |
| Режим: удерживать / нажать-отжать | удерживать | `savegame.mod.toggle` |
| Скорость при старте x0,5 / x0,25 / x0,1 | x0,25 | `savegame.mod.preset` |
| Плавность 0,05-1,5 с | 0,35 с | `savegame.mod.ramp` |
| Шкала энергии | вкл | `savegame.mod.energy` |
| Энергии хватает на 2-60 с | 8 с | `savegame.mod.capacity` |
| Полная перезарядка 2-60 с | 12 с | `savegame.mod.recharge` |
| Синий оттенок 0-1 | 0,8 | `savegame.mod.tint` |
| Быстрее ходьба в замедлении | выкл | `savegame.mod.walk` |
| Подсказка при старте | показывать | `savegame.mod.hint` |

## Установка, сборка, проверка

```powershell
New-Item -ItemType Junction -Path "$env:USERPROFILE\Documents\Teardown\mods\time-slow" -Target "$PWD\mod"   # run inside the mod folder
..\_shared\.venv\Scripts\python tools\build_all.py
```

Mod Manager -> Local files -> Time Slow -> включить. Это не инструмент: работает с любым инструментом в руках.

# Торнадо (мод для Teardown)

Инструмент вызова бури. English: [README.md](README.md).

- **ЛКМ** создаёт торнадо в точке прицела (до 2 одновременно), **ПКМ** развеивает ближайший (он стихает за 3 с).
- Торнадо около 3 с формируется на месте, потом движется: по плавному случайному пути (поворот по шуму, у границы карты разворачивается назад) или к точке прицела (настройка).
- Воронка: радиус растёт с высотой (0,6 м у земли до «размера» наверху, высота = 3,6 x размер), ось изгибается и качается. Частицы: закрученная стена дыма, тёмная внизу и светлая вверху, кольцо пыли у основания, тёмные обломки, летающие по кругу и вылетающие наружу, тусклый свет наверху. Рёв ветра (номинальная дальность 60 м, поэтому при приближении становится громче), гром при появлении, затихающий порыв в конце, тряска камеры рядом.
- Силы: тела ближе 1,6 x размера к оси затягиваются, закручиваются и поднимаются; выше 82% высоты выбрасываются наружу. Тяжёлым достаётся меньше (`1200 / (1200 + масса)`), добавляемая скорость ограничена. Масштаб изменения скорости близок к собственному торнадо игры.
- Машины и игрока можно поднимать (настройки); стена между игроком и воронкой его прикрывает; совсем рядом игрок роняет то, что держит.
- Разрушения в пределах бюджета: 2 пробы `QueryClosestPoint` за физический шаг вокруг нижней части воронки; дыры в стекле, дереве, штукатурке, пластике и листве, бетон и слабый металл только при силе 2 и выше; каждые 0,3 с отрываются до 2 соединений поднятых тел. Не больше 600 дыр на торнадо.

Бюджет: один `QueryAabbBodies` раз в 0,25 с на торнадо, до 150 тел, 50 импульсов за шаг (по кругу);
32 частицы за шаг на все торнадо вместе.

В игре есть свой внутренний торнадо (`data/script/tornado.lua`) с помощниками на C++ `TornadoSpawnParticlesCPP` / `TornadoBodiesSuctionCPP`.
В `script_defs.lua` они без описания параметров, поэтому мод считает физику и частицы сам на Lua.

## Настройки

| Настройка | По умолчанию | Ключ |
|---|---|---|
| Сила x0,3-x3 | x1 | `savegame.mod.strength` |
| Размер (радиус вверху) 4-20 м | 8 м | `savegame.mod.size` |
| Время жизни 10-180 с | 40 с | `savegame.mod.duration` |
| Скорость движения 1-12 м/с | 4 | `savegame.mod.speed` |
| Движение: бродит / идёт за прицелом | бродит | `savegame.mod.follow` |
| Поднимает машины | да | `savegame.mod.vehicles` |
| Поднимает игрока | да | `savegame.mod.player` |
| Рвёт постройки | да | `savegame.mod.damage` |

## Установка, сборка, проверка

```powershell
New-Item -ItemType Junction -Path "$env:USERPROFILE\Documents\Teardown\mods\tornado" -Target "$PWD\mod"   # запускать в папке мода
..\_shared\.venv\Scripts\python tools\build_all.py
```

Mod Manager -> Local files -> Tornado -> включить; инструмент «Вызов бури» в последней группе.

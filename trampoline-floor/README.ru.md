# Пол-батут (мод для Teardown)

Батуты и режим, в котором прыгает вся земля. English: [README.md](README.md).

| Ввод | Действие |
|---|---|
| ЛКМ | поставить батут 3 x 3 м на ровную землю (до 8) |
| ПКМ | убрать ближайший батут |
| R | режим «вся земля прыгает» вкл / выкл |

- Батут - своя воксельная модель (синяя рама с пружинами и жёлтой полосой, чёрная сетка, огни по углам), ставится статичным телом на землю лицом к вам.
- Упругости поверхностей в Teardown нет, поэтому отскок - это смена скорости на сервере. Касание ищется по положению: если низ падающего игрока или тела окажется у сетки батута (или, в режиме «вся земля», у статичной земли под ним) до следующего шага физики, его скорость падения - или запомненная за последние 0,25 с, если движок уже успел его остановить, - умноженная на упругость, возвращается вверх через `SetPlayerVelocity` / `SetBodyVelocity`. Упругость по умолчанию 1,05: каждый отскок чуть выше падения, до предела скорости (30 м/с). Прыжок в момент касания добавляет +6 м/с, так можно с каждым отскоком взлетать всё выше. Падающие тела проверяются каждый шаг физики (по кругу, если их больше 60), высота земли запоминается для каждого тела; закон с числами в `tests/bounce_law.lua`: падение с 5 м возвращает на 5 м и выше игрока, ящик и машину, на батуте и в режиме «вся земля», и 60 ящиков, упавших разом, отскакивают все.
- Прыгать могут игроки, предметы и машины (каждое отключается). Тела ищутся через `QueryAabbBodies` над батутами и, в режиме «вся земля», в радиусе 30 м от игроков, раз в 0,25 с; за физический шаг проверяется 40 тел.
- Эффекты: «бойнг» (два варианта, высота по силе удара), кольцо пыли, сетка батута прогибается и пружинит (анимирует сервер, батут принадлежит серверу), мягкий свет над батутами, пока инструмент в руках.

## Настройки

| Настройка | По умолчанию | Ключ |
|---|---|---|
| Упругость 0,3-1,5 | 1,05 | `savegame.mod.restitution` |
| Макс. скорость отскока 5-60 м/с | 30 | `savegame.mod.maxspeed` |
| Прибавка от прыжка 0-15 м/с | 6 | `savegame.mod.jumpboost` |
| Игроки прыгают | да | `savegame.mod.players` |
| Предметы прыгают | да | `savegame.mod.bodies` |
| Машины прыгают | да | `savegame.mod.vehicles` |
| Радиус режима «вся земля» 10-80 м | 30 | `savegame.mod.radius` |
| Вся земля прыгает со старта | нет | `savegame.mod.global` |

## Установка, сборка, проверка

```powershell
New-Item -ItemType Junction -Path "$env:USERPROFILE\Documents\Teardown\mods\trampoline-floor" -Target "$PWD\mod"   # запускать в папке мода
..\_shared\.venv\Scripts\python tools\build_all.py
```

Mod Manager -> Local files -> Trampoline Floor -> включить; инструмент «Батуты» в последней группе.
